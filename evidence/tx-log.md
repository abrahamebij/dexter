# Dexter transaction log

Every real transaction sent by the guardian is recorded here with its hash, the guard that fired, and the position before and after.
Entries are copied from the Activity page and the server event log. Nothing in this file is simulated or invented.

| Date (UTC) | Guard | Market | Action | Tx hash | Position before | Position after |
|---|---|---|---|---|---|---|

Dry-run simulations are not listed here. They appear in the Activity page as `simulated` events.
